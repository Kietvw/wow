# WoW addons

Personal addons for World of Warcraft Classic (Era, Anniversary and TBC Anniversary).

## Addons

- [LayerSwap](addons/LayerSwap/README.md): shows which layer you are on and asks hosts for a swap (`/ls`)
- [AHAdvisor](addons/AHAdvisor/README.md): scans the auction house, learns prices and suggests what to buy, sell and craft (`/aha`)

## Install

Copy an addon's folder from `addons/` into your `Interface/AddOns` directory, so the result is for example `Interface/AddOns/AHAdvisor/AHAdvisor.toc`.
