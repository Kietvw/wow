# LayerSwap (custom)

A personal build of the LayerSwap addon by Adam5288 for World of Warcraft Classic (Era, Anniversary and TBC Anniversary). It shows which layer you are on and asks LayerSwap hosts for a swap to another layer.

## Changes from upstream

- **Hosting is off by default and stays off.** It no longer turns on at login, after a reset, or by itself. It turns on only when you switch it on with the Host button, the options checkbox or `/ls host`, and it stays as you set it.
- The combat restriction is removed.
- The players who respond to an ask are shown in a list.

## Install

Copy this `LayerSwap` folder into your `Interface/AddOns` directory, so the result is `Interface/AddOns/LayerSwap/LayerSwap.toc`.

## Usage

Type `/ls` in game to open the panel.
